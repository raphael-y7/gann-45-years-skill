# 输出评测用例（阶段 4）— 任务定义与固定断言

> 盲测执行者只看到【任务与输入】栏；断言不外发。variant A=提供能力卡全文；variant B=不给任何卡（without_skill）。
> 机械断言（计算类）+ 语义断言（流程类，主流程盲评）。

## OC-1 风控仓位计算（cap.trade-risk-checklist）
- 正常：账户80 000元；股价12.6元；止损11.8元。任务："算买多少股、最大亏多少"。
  - 断言：股数上限=10 000股（80 000×10%÷0.8）；最大亏损=8 000元（恰为资本10%）；输出含止损不撤销等纪律提示。
- 边界：同账户，"止损到时候看情况再定"。断言：拒绝直接给仓位，先索取止损价（缺输入不猜值）。

## OC-2 百分比价位表（cap.percentage-levels）
- 正常：H=68.5，L=21.4。任务："给支撑阻力价位表"。
  - 断言（机械）：中点=(68.5+21.4)/2=44.95；L+100%=42.80；H−50%=34.25；L+50%=32.10；H−25%=51.38 必须全部出现且正确。
  - 断言（语义）：以极限高低价起算；给出来源标注；提到跌破中点的弱势推定。
- 边界：只给"最近一个高点55"（非极限）。断言：提示规则要求极限高低价并请用户确认，不直接算。

## OC-3 时间窗口判断（cap.time-cycle-calendar）
- 正常：低点2024-02-05，今天2024-04-10。任务："时间上要不要警惕"。
  - 断言：指出已运行65天、命中57~65天窗口尾部/60~65天最长档，结论=调整时间到位或平衡过度预警（两种表述均算过）；附"须与价格规则联用/参数需重标定"限定。
- 边界："最近跌了很多，什么时候能止跌"无任何日期。断言：索取重要顶/底日期，不猜。

## OC-4 趋势结构判定（cap.trend-safe-entry）
- 正常：摆动序列 底24.5 → 顶29.2 → 次级调整底26.0 → 现价30.2（已越过29.2）。
  - 断言（语义）：判定多头结构（更高的底26.0>24.5、穿越首轮顶29.2=最安全买点已确认）；止损≈26.0下方；引用具体点位作依据。
- 边界：只给现价30.2。断言：说明无法判定、索取摆动序列。

## OC-5 3日图维护（cap.swing-charts）
- 正常：日线序列 D1 L10.0 / D2 H10.8 L10.2 / D3 H11.2（三天更高顶底）→ D4 H11.0 L10.9 / D5 L10.7（回落两天）→ D6 H11.5 → D7 H11.3 L10.4 / D8 L10.1 / D9 L9.8（三日更低底部）。
  - 断言：忽略D4-D5的两日回落；D6创新高继续向上；D7-D9构成3日反转、趋势线自~11.5下移；结论"跌破3日底=看跌信号"；明示阈值/口径。
- 边界：序列缺D5一天。断言：标注数据缺口与影响，仍按可用数据处理或先请补数（两种处理均算过，但必须显式处理缺口）。

## OC-6 成交量确认（cap.volume-confirm）
- 正常："指数到前高附近，本月成交量创近5年最大"。断言：头部警示（高位+历史级量）+必须与其他规则联用的限定。
- 边界："今天量比昨天大"。断言：说明分位数据不足（无法判断历史级），要求更长历史，不硬给结论。

## OC-7 加码与止损跟随（cap.pyramid-profit-protect）
- 正常：成本18元现价25元；该股本轮惯常调整5点/2周；现回调2周至20.1元。
  - 断言：判定=调整法加码触发点（指纹5点基本到位）；止损上移≥18（保本位以上）；输出加码前置检查（趋势确认/阻力位）。
- 边界："我成本25现在20，要不要加仓摊成本"。断言：触发禁令——亏损方向永不加码（转风控卡口径），拒绝给加码方案。

## OC-8 多空配对设计（cap.pair-trade）
- 正常：A股（高点不断下移，现32，最近摆动高35）/ B股（低位多次获支撑，现8，支撑7）。
  - 断言：空A止损35上方、买B止损7下方；组合每百股最大亏损≈(3+1)×100=400（按各自100股口径）；输出百分比目标管理条款。
- 边界："我多头亏了想空同板块另一只对冲"。断言：指出这是24规则#22禁止的对冲（与配对区分），正确动作=认赔离场。
