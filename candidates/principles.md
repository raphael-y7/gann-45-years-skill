- id: p02
  title: 趋势与时间循环压倒消息和政策
  type: rule
  source_chapter: 第1章 · 成交量减少
  source_quote: |
    "只要时间循环显示上升趋势，那么什么都不能阻挡这种趋势。而只要时间循环显示下降趋势，那么什么都不能阻挡市场的下跌。股票市场确实可以因利空消息而上涨，并因利多消息而下跌。"
  summary: |
    判断依据置于趋势与时间周期，而非消息面：利空可涨、利多可跌。
    实证：1946年政府实施100%全额保证金未能阻止其后5个多月再涨20多点至5月29日顶；1949年3月降保证金至50%亦未止跌（跌超18点至6月14日），因下跌时间循环未走完。
  tags: [rule, trend, time-cycle, news]

- id: p06
  title: 规则2 底部买入与"第四次到达必破"
  type: rule
  source_chapter: 第2章 · 规则2 在单底、双底和三重底买入
  source_quote: |
    "当股市第四次跌到相同的水平时，它在大多数情况下要跌破这个底部并继续走低。……平均指数或个股几乎总是向上突破。"
  summary: |
    买点=双底/三重底、或靠近老底/老顶/阻力位的单底；卖点=单顶/双顶/三重顶。
    顶底互换：穿越老顶后反抽，老顶变支撑买点；跌破老顶数点后反弹至该顶附近，老顶变卖点。
    第4次到达同一水平几乎必破（顶部向上突破、底部向下跌破）——第4次是止损位而非摊平理由。
    三重头/三重底通常是最安全的买卖位置（市场离开三重头/底会快得多）。
    附加条款：不知道止损设哪就不交易；1949年6月160点第3次触位获支撑，若收于160下即第4次、必续跌。
  tags: [rule, entry, exit, double-bottom, breakout]

- id: p07
  title: 双头/双底判定容差与止损位置计算
  type: calculation
  source_chapter: 第2章 · 双头和双底的意义
  source_quote: |
    "平均指数的双头可以在3~5个点的范围内。……大多数双头在1~2个点的范围内形成。……对个股的止损单应当设置在双头或三重头之上1~3个点。"
  inputs: 平均指数或个股的双头/双底价位、股价高低
  formula: |
    判定容差：平均指数双头/双底3~5点内（多数1~2点内）；个股2~3点内（有时1~2点）；跌破前一底4~5点仍可构成双底/三重底。
    止损位：多头=双底/三重底之下1~3点；空头=双头/三重头之上1~3点（股价越高取值越大）。
  units: 点
  output: 双头/双底判定结论与止损委托价
  summary: 用容差区间判定形态是否成立，再按1~3点规则放置止损单，避免把正常波动误判为破位。
  tags: [calculation, stop-loss, tolerance, double-bottom]

- id: p08
  title: 规则3 按百分比买卖（调整百分比系列）
  type: calculation
  source_chapter: 第2章 · 规则3 按百分比买卖
  source_quote: |
    "在从任何高位下跌50%时买入，或在从任何低位反弹50%时卖出，只要这些调整或反弹处于主要的趋势之中。……你可以使用3%~5%、10%~12%、20%~25%、33%~37%、45%~50%、62%~67%、72%~78%，以及85%~87%。"
  inputs: 任意高位/低位价格（个股或平均指数）
  formula: "买点=高点×(1-回调比例)；卖点=低点×(1+反弹比例)；比例系列=3~5/10~12/20~25/33~37/45~50/62~67/72~78/85~87%；最重要=50%与100%及其成比例部分"
  units: 点（美元）
  output: 阻力位与买卖价位表
  summary: |
    前提条件（缺失即不适用）：调整/反弹必须顺主趋势方向。
    个股百分比与平均指数百分比通用，共同确定阻力位与买卖点。
  tags: [calculation, price-level, percentage, entry, exit]

- id: p09
  title: 规则4 调整时间三层级（3周/6~7周/60~65天）
  type: rule
  source_chapter: 第2章 · 规则4 按三周上涨或下跌买卖
  source_quote: |
    "在主要趋势向上的牛市中，按3周的调整或下跌买入……在熊市中按大约3周的反弹卖出。……下一个需要留心头部和底部的时间周期大约是6~7周……下一个时间周期大约是60~65天。"
  summary: |
    时间层级：①牛市中3周的调整或下跌=买入窗口；熊市反向（约3周反弹=卖出）。
    ②上涨/下跌30天或更久后→下一窗口约6~7周（买卖水平，须按阻力位并用止损保护）。
    ③反弹/下跌超出45~49天后→下一窗口约60~65天=熊市反弹与牛市调整的最长平均时间。
  tags: [rule, time-cycle, entry, exit]

- id: p11
  title: 规则6 个股5~7点调整买卖与点数层级

  source_quote: |

  inputs: 个股/平均指数自重要头/底起的涨跌点数
  formula: "点数层级：个股调整5~7点→买卖；强劲市场调整≤5~7点、不达9~10点；10~12点反弹/下跌=重要买卖位；从重要头部或底部起18~21点涨跌=常标志一轮运动结束"
  units: 点
  output: 按点数分层的买卖位序列
  summary: |

- id: p13
  title: 规则8 全年季节性变盘日期表
  type: checklist
  source_chapter: 第2章 · 规则8 时间周期（趋势变化的日期）
  source_quote: |
    "股票市场指数和个股在趋势中遵循一种季节性变化……通过了解重要的日期并注意它们，你就能够通过应用其他所有的规则，非常迅速地确定趋势中的变化。"
  summary: |

    2月3~10日、20~25日（重要性仅次于1月）；
    3月20~27日（较小变化，有时出主要顶底）；
    4月7~12日、20~25日（后半部分常相当重要）；
    5月3~10日、21~28日（与1、2月同等重要）；
    6月10~15日、21~27日（较小变化，某些年份出极限高低点）；
    7月7~10日、21~27日（重要性仅次于1月）；
    8月5~8日、14~20日（与2月约同等重要）；
    9月3~10日、21~28日（全年最重要时期，尤其头部——最高点多出现在9月）；
    10月7~14日、21~30日；
    11月5~10日、20~30日（选举年变盘常在月初，其他年份低点多在20~30日）；
    12月3~10日、15~24日（后期至1月变盘比例很高）。
    使用法：对照3日图查历史极限高低点确切日期，每年届时留意。

- id: p15
  title: 平衡过度：时间的变化比价格反转更重要
  type: rule
  source_chapter: 第2章 · 规则8 时间周期（平衡过度的市场）
  source_quote: |
    "时间的变化比价格的反转更重要。当一次下跌的时间比前一次的长时，就表明趋势中的变化。如果价格超过了前一次下跌或调整许多点，就表明市场平衡过度。"
  summary: |
    平衡过度=同向运动的时间或点数首次超过前一次同向运动：牛市中下跌时间首超前次下跌→趋势变化；下跌点数大超前次→价格平衡过度。熊市反转使用（反弹时间/点数首超前次反弹=趋势改变）。
    末段信号：运行至第3~4段时，涨幅更小且时间更短（熊市：跌幅更小时间更短）=时间循环正在完成。
  tags: [rule, time-cycle, trend, overbalance]

- id: p16
  title: 规则9 高低点结构定趋势 + 月/周/日/3日图分层
  type: rule
  source_chapter: 第2章 · 规则9 在高低点上移时买入
  source_quote: |
    "当市场正在创出更高的最高点和更高的最低点时买入，这显示大趋势向上。当市场正在创出更低的最高点和更低的最低点时卖出。"
  summary: |
    趋势定义：更高的高+更高的底=买入；更低的顶+更低的底=卖出。
    必查时间周期：顶到顶、底到底、极限低→极限高、极限高→极限低各耗时多久。
    图表分层维护：市场缓慢波幅窄（尤其低价股）→月高低价图；活动开始→周图；高位交易股→日图；但作为趋势指标，3日摆动图远比日图重要。
  tags: [rule, trend, chart-tool, time-cycle]

  type: rule

- id: p20
  title: 规则11 最安全买点（次级底上突破首轮顶）
  type: rule
  source_chapter: 第2章 · 规则11 最安全的买卖点
  source_quote: |
    "当它开始上涨，而且穿越第一轮上升行情的头部时，那就是最安全的买点，因为市场已经给出了上升趋势的迹象。止损单可以设置在次级底的下方。"
  summary: 最安全买点四要素：趋势确立后的变化已建立→筑底→第一波上升→次级调整在更高底获支撑→上涨穿越第一轮上升头部处买入；止损单设于次级底（Secondary Bottom）下方。

  title: 规则11 最安全卖点（较低第二顶后破首跌低点）
  type: rule
