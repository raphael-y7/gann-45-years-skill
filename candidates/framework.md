- id: f03
  title: 趋势判定与选股一致性流程（规则1+规则9）
  type: procedure
  source_chapter: 第2章 规则1 确定趋势 + 规则9 在高低点上移时买入；第7章 开篇（道氏理论修正）
  source_quote: |
    "确定道琼斯30种工业股平均指数……或任何关于你要交易的股票群的平均指数的趋势，然后在你要交易的股票群中挑选股票，并看它的趋势迹象是否与平均指数显示的趋势一致。"／"当市场正在创出更高的最高点和更高的最低点时买入，这显示大趋势向上。"
  summary: |
    自上而下的三层判定：平均指数趋势 → 股票群（行业指数）趋势 → 个股趋势，三层一致才交易。
    趋势判据：更高的高点+更高的低点=多头（买入）；更低的高点+更低的低点=空头（卖出）。
    择时工具用3日图+9点摆动图；同时检查头部至头部、底部至底部、极限低点到极限高点的时间周期。
    道氏修正：不要求铁路股指数印证工业股指数；改为关注显示强势/弱势的个股本身，把工业股平均指数作一致趋势指标。
  inputs:
    - 平均指数月/周/日高低价走势图与3日图、9点摆动图
    - 目标股票群指数与个股走势图
  outputs:
    - 大趋势结论（多/空/区间）+ 与指数一致的候选股名单
  steps:
    - 确定所交易股票群对应平均指数的趋势
    - 在该股票群中挑选个股，核对其趋势迹象是否与指数一致
    - 用"更高高点+更高低点 / 更低高点+更低低点"确认方向
    - 用3日图与9点摆动图+时间周期确定买卖时机
  missing_conditions:
    - 指数与个股趋势矛盾时的裁决规则未明说（仅第3章以个案示意"按个股自身趋势操作"）
  tags: [trend, stock-selection-skill, procedure, core]

- id: f04
  title: 双底/三重底买卖与顶底互换框架（规则2）
  type: framework
  source_chapter: 第2章 规则2 在单底、双底和三重底买入 + 双头和双底的意义
  source_quote: |
    "当市场穿越先前的头并反抽，或略微跌破时，那些是卖点的头或天花板就变成了底、支撑或买点。"／"平均指数或个股第四次到达相同的水平时，卖出就不太安全，因为……几乎总是向上突破。"
  summary: |
    三条 if-then 规则：(1) 顶底互换——老顶被有效穿越后变为支撑/买点，老底被有效跌破后变为阻力/卖点；
    (2) 第四次测试同一水平几乎必破（顶部第四次到量=向上突破前兆，底部反之），第三次到达（三重顶/底）通常是
    最安全的买卖位，因为离开三重头/底的运动快得多；(3) 有效突破确认容差——须破老顶/阻力位之上5点（或跌破
    老底5点内仍不改势）。双头双底有容差：平均指数1-5点、个股1-3点范围内算同一水平；止损设在双底/三重底
    下方1-3点（视股价高低）。交易后立即确定止损位并交给经纪人；不知道止损放哪就不交易。
  tags: [support-resistance, entry-signal, confirmation, core]

- id: f05
  title: 最安全买卖点判定程序（规则11）
  type: procedure
  source_chapter: 第2章 规则11 最安全的买卖点
  source_quote: |
    "当股票筑底并有了一波上升行情之后，会是次级调整，而且它在一个更高的底部获得支撑。当它开始上涨，而且穿越第一轮上升行情的头部时，那就是最安全的买点……止损单可以设置在次级底的下方。"
  summary: |
    买点时序结构：筑底 → 第一波上升 → 次级调整（在更高底部获支撑）→ 穿越第一轮升势顶部 = 最安全买点
    （趋势已给出上升迹象），止损设于次级底下方。卖点对称：长期上涨创最后高点 → 第一次陡直快跌 → 反弹
    形成较低的第二个顶 → 跌穿第一次下跌的最低点 = 相对安全卖点（主趋势调头向下信号）。
    附加强势判定：快速市场中仅持续2天的调整/2日反弹不进第三天=强势位置。配套纪律：只要趋势向上没有太高
    而不能买的股票，反之亦然；永远顺势、用止损保护、强势中买入弱势中卖出。
  inputs:
    - 个股/指数的摆动序列（底、第一轮升势顶、次级底）
  outputs:
    - 最安全买卖点 + 止损位（次级底下方）
  steps:
    - 等趋势中的变化已经确立（不抄第一底）
    - 识别次级调整是否在更高底部获得支撑
    - 等待穿越第一轮升势顶部的确认信号再买入
    - 止损单置于次级底下方
  missing_conditions:
    - "次级底"与普通反弹底的量化区分口径需结合3日图/9点图（见f17/f18）
  tags: [entry-signal, exit-signal, procedure, core]

- id: f06
  title: 百分比阻力位计算程序（规则3+第4章）
  type: procedure
  source_chapter: 第2章 规则3 按百分比买卖；第4章 最高价和最低价的百分比（含"在50%水平以下交易的股票""市场活动证实了这些规则"）
  source_quote: |
    "我最伟大的发现之一是如何计算平均指数和个股的最高价和最低价的百分比。极限最高价位和最低价位的百分比预示着未来的阻力位。"／"最重要的阻力位是任何最高价或最低价的50%。"
  summary: |
    核心计算框架：以极限最高价/极限最低价（而非任意起算点）按固定百分比外推，得到支撑/阻力价位网络。
    百分比优先级：50%（最重要）> 最低价100%及与100%成比例的倍数（200%、300%…视价格与时间周期而定）
    > 25% > 12.5% > 6.25%（仅极高价位时用）> 33⅓%/66⅔%。调整区间百分比：3~5%、10~12%、20~25%、
    33~37%、45~50%、62~67%、72~78%、85~87%。同时计算极限高低价之间的中点（50%点）。
    若跌破50%位置且无支撑站稳=极弱，预示去75%或更低；最高价的50%更重要，跌破后不见支撑迹象不买。
    验证法（第4章"市场活动证实了这些规则"）：对历史每个顶底反查百分比表是否"在场"，再前瞻应用。
  inputs:
    - 极限最高价、极限最低价（指数或个股），及重要次级顶底价
  outputs:
    - 百分比阻力位表（上涨序列与下跌序列）+ 极限区间中点表 + 买卖位与止损参考
  steps:
    - 找出极限最高价与极限最低价
    - 以低价为基础加 50%/100%/200%… 生成上涨阻力表；以高价为基础减 25%/50%/75%/87.5%… 生成支撑表
    - 计算各重要高低点对之间的中点（50%点）
    - 价格到达重要阻力位/老顶/老底时，将全部规则转用于所交易个股
  missing_conditions:
    - 书中所有算例基于1949年前道指点位，绝对点位标尺对现代市场失真（须换算为百分比/波动率口径，见BOOK_OVERVIEW批判节）
  tags: [price-level, calculation, support-resistance, core, gann-specific]

- id: f10
  title: 平衡过度判定法（Overbalanced）
  type: reasoning
  source_chapter: 第2章 规则8 时间周期（平衡过度的市场）
  source_quote: |
    "当一次下跌的时间比前一次的长时，就表明趋势中的变化。如果价格超过了前一次下跌或调整许多点，就表明市场平衡过度，因而趋势中的变化正在发生。"／"时间的变化比价格的反转更重要。"
  summary: |
    以"前一次同向运动"为基准的推理法：本次下跌/反弹的时间首次超过前一次 → 趋势变化信号；价格首次超过
    前一次调整许多点 → 价格平衡过度。牛市末段征兆：第三/第四段的涨幅更小、时间更短（熊市对称：跌幅更小、
    时间更短=时间循环正在完成）。熊市中规则反转使用（反弹首次超时/超幅=转势迹象）。判定的核心权重给时间
    而非价格。
  tags: [trend-change, time-cycle, reasoning, core]

- id: f11
  title: 市场分段运动模型（规则5）
  type: mental-model
  source_chapter: 第2章 规则5 市场分段运动
  source_quote: |
    "当市场在向上的运动中走了第一段时，永远不要认为它已经到达了最终的头部，因为如果这是一个真正的牛市，它会在到达最终的高点之前至少运行3段，也可能是4段。"

    底部。用于抑制"第一段就下车/抄底"的冲动，与f05（次级调整后再入场）、f13（序列模型）配合使用。

  title: 快速运动速度与正常幅度判定（规则12）
  type: framework
  source_chapter: 第2章 规则12 快速运动中的价格增进；第5章（应用判例）
  source_quote: |
    "当市场非常活跃，而且上涨或下跌得十分迅速时，它们平均每个日历日运动1点左右。当平均指数或个股的运动是每天2点或更多时，它就很不正常，因而不会持续得很久。"
  summary: |

    市场；牛市中调整不足10点=强势。用于判定"太快必反弹"和动能衰竭。

- id: f14
  title: 重要摆动时间记录研究法
  type: procedure
  source_chapter: 第6章 平均指数重要摆动的时间周期；第8章 道琼斯30种工业股平均指数的时间摆动
  source_quote: |
    "如果你有工业股平均指数每次重要摆动所需时间的记录，并且你知道涨跌的幅度，那么你就能够说明未来市场会运行多长的时间周期，而且你能在每个重要时间周期——以往重复次数最多的循环——的尾声留心趋势中的变化。"
  summary: |

- id: f17
  title: 3日图维护与信号读取程序
  type: procedure
  source_chapter: 第7章 维持3日图的规则 + 3日或更久的运动
  source_quote: |

  summary: |

    顶部；2日倒退不记录，除非市场处于极限高低点附近且振荡剧烈（此时可记1-2日运动）。下跌对称处理。
    信号读取：跌破3日底=至少小趋势反转向下；穿越3日头=至少暂时反转向上；双头/三重头后跌破3日底=小趋势
    确认向下。辅助判定：市场停留在狭窄交易区间、既不破前摆动低点也不穿前顶时，不算大势改变；突破区
    间才算。时间维度并行检查：穿越/跌破所用时间越长，后续运动越大；并核对距极限高低点的总时长。
  inputs:
    - 日线高低价数据（指数或个股）
  outputs:

    - 出现3日较低底部→趋势线下移至第3日低点，随新低延续

    "看到趋势变化迹象才卖，一见确证立即卖"；对过迟型交易者，强制挂远距（10~20点）止损单作为兜底。
